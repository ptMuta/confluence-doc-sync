# git-confluence-sync

GitHub Action that publishes a repository's structured docs (decisions, requirements, security, logging, monitoring and draw.io diagrams) to Confluence Cloud.

Status: in development.

## Development

Node 24. `npm ci --ignore-scripts`, then `npm run verify` runs type checks, lint, formatting, tests with coverage, Knip and the build.
